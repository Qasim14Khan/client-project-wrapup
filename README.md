# Client Project Wrap-up

A Skill for photographers, video editors, designers and freelancers who keep client work on a UGREEN AI NAS.

Finishing a project usually means the same chore every time: gather the final files, copy them into a delivery folder, check the contract and invoice, build an album for the client and write a summary. This Skill does it from one sentence.

## Say something like

- "Wrap up the Ahmed wedding project."
- "Prepare delivery for my client, the shoot was last weekend."
- "Close out the product shoot for Zara."

## What happens

1. You tell it the project name and where the files are (or the shoot dates).
2. It finds the real photos, videos and documents there.
3. It reads the contracts and invoices and pulls out parties, amounts and due dates.
4. It shows you the plan and waits for your yes.
5. It copies the final files into a delivery folder and creates a delivery album.
6. It saves a short project summary next to the delivery files.

## Safety

- Your original files are never moved, renamed or deleted.
- Nothing is changed until you confirm.
- If nothing is found, it says so and stops. It does not guess or search elsewhere.
- Existing files are never overwritten.

## Limits

- One project at a time.
- Album contents depend on how the NAS photo features recognise dates and places in your photos.
- This is a community-built Skill, not an official UGREEN Skill.
